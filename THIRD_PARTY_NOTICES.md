## Dependencies installed at build time

Python and npm dependencies are not stored in this repository. They are installed from
their package registries and keep their own licenses. ASVA's own Python dependencies
(`requirements*.txt`, `security_context/requirements*.txt`) use permissive licenses
(MIT, BSD, Apache 2.0). Some target-application dependencies use weak copyleft licenses
(for example `psycopg2`, LGPL-3.0); they are used unmodified, as installed packages.

## External tools and services

The pipeline calls these tools and services. None of them are included in this repository:

- [gitleaks](https://github.com/gitleaks/gitleaks) (MIT)
- [Snyk CLI](https://github.com/snyk/cli) (Apache 2.0). Scans need a Snyk account, which has its own terms.
- An Ollama-compatible LLM endpoint, configured through `OLLAMA_HOST`. Model weights have their own licenses.
